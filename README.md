# Sales & Revenue Analysis Dashboard - Next Gen Software

## 📌 Project Overview
This repository features an interactive **Power BI** dashboard built as part of the data analytics internship project at **Next Gen Software Hub**[cite: 4]. It analyzes overall business sales, revenue trends, and product performance to generate actionable insights.

## 🛠️ Key Features & Tech Stack
- **Power BI Desktop:** Utilized for data modeling, layout design, and interactive data visualization.
- **KPI Cards:** Highlights core business metrics including Total Revenue, Total Sales Amount, and Units Sold.
- **Interactive Visuals:** 
  - Clustered Bar Chart for Region-wise Sales analysis.
  - Donut Chart for Revenue distribution by Product Category.
  - Line Chart tracking Monthly Sales Trends.
- **Dynamic Slicers:** Integrated Date Range sliders and Region dropdown filters for real-time data filtering.
